# AI-Cyber-Threat-Detection

AI-powered detection and classification of cyber threats in unidirectional IP traffic.

## 1. Project Overview

This project focuses on detecting and classifying potential cyber threats using AI-based techniques and network traffic data.

## 2. Objectives

- Detect potential cyber threats.
- Analyze security-related network traffic.
- Classify detected threats.
- Provide useful information for threat analysis.
